# YoHAM
Minecraft Plugin

## Dependencies
Java Development Kit (JDK) >= 25

## Setup
JDK path needs to be specified in:
- a) IDE Project Structure (IntelliJ)
- or b) 'gradle.properties' file in project root

## What is this? TODO?
* Gradle with Frabic
* Using Simple Voice Chat (limited to proximity)
* Global voice chat is in morse code
* Each player starts in a different sector
* Simulated environments:
  - ionosphere propogation, bounce to go further in daytime
  - higher up for better propogation
  - gains
* Communications
  - proximity speakers
  - Base stations, mobile receivers
  - Handhelds
  - Underground capabilities, repeaters
  - Cross dimensions
  - Close range and long range
* Progression Tree
  - Slow progression with more perks as you make more things
